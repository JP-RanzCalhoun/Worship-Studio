# Contributing

- Setup: see `docs/SETUP.md`. Architecture: `docs/ARCHITECTURE.md`.
- Run `npm test` in `ui/` before sending changes.
- Never commit audio, video, stems, model weights, or credentials (see `.gitignore`).
- Check the license of any new dependency or model and add it to `docs/LICENSES.md` first.
- Do not present uncertain analysis as fact in the UI. Show confidence, keep user corrections.
- The project license is not decided yet.
